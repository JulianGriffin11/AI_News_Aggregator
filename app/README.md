This folder holds app-level code: scrapers, agents, database models, and services.

- `scrapers/` — source-specific scrapers (YouTube, RSS, etc.)
- `agent/` — LLM-driven agents to summarize, rank, and produce email text
- `database/` — DB models and repository helpers
- `services/` — processing and email sending helpers
- `profiles/` — user profile examples for personalization
